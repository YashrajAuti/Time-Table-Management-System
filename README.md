## 📌 About Project
A DBMS-powered web application that automates timetable generation for educational institutions using rule-based scheduling logic and relational database design.

---

## ⚙️ Tech Stack
- HTML, CSS, JavaScript  
- Python (Flask)  
- MySQL / SQLite  
- DBMS (Normalization + Query Design)  

---

## 🚀 Features
- 📅 Automated timetable generation  
- ⚖️ Conflict-free scheduling system  
- 🧠 Rule-based logic engine  
- 🗄️ Normalized database (3NF)  
- 👨‍🏫 Faculty allocation management  
- 🔄 Full CRUD operations  
- 💻 Clean UI for scheduling
